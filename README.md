## 開始方法

「住所から世界をひらく」で住所・地名を検索し、候補の場所を確認して開始できます。「現在地からはじめる」でブラウザの位置情報を許可するか、緯度・経度を指定する方法にも対応します。プレイ中も「場所を選ぶ」から移動先を変更できます。遊ぶ場所は、現在地・住所検索・指定座標から読み込む実在の街です。

初期の取得範囲は通常の端末で半径250m、タッチ主体の端末で150mです。150m・250m・450mから選べます。地図と標高を同時に取得し、地図の接続に失敗した場合は、位置情報を取り直さずに同じ地点を半径150mで再試行できます。標高だけを取得できなかった場合は、その旨を表示して平面の地形を使用します。

OpenStreetMapの建物輪郭・道路中心線と、公開DEMの標高を使います。外壁・窓・室内、未登録の高さや道路幅はゲーム用の表現です。現地の写真や私室を復元する機能ではなく、実世界の通行を案内するナビゲーションでもありません。

位置が建物や水域の中に重なる場合、歩ける屋外を開始点にし、移動した距離を表示します。地図には取得した元の位置も残します。測位に失敗した場合は住所検索か座標指定で場所を選び、地図取得に失敗した場合は同じ地点を小さい範囲で再試行できます。

## キャラクター

- 標準キャラクターと服の色を選べます。
- 正面、背面、左右の写真から、輪郭を使った簡易3Dキャラクターを作成します。これはAIによる精密復元やフォトグラメトリではありません。精細度を上げても、写真にない形は復元されません。
- 写真モデルの精細度は標準・高精細・超高精細・シネマティックから選べます。シネマティックは最大952,320三角形（約95.2万ポリゴン）です。端末が報告するメモリ・CPU情報やタッチ操作に応じて高精細または超高精細へ制限する場合は、画面に知らせます。待機・歩行・走行・ジャンプの動作を付けます。
- テクスチャ内蔵のGLB / VRMを読み込めます。上限は50MB・200万ポリゴン。付属アニメーション、または対応する人型骨格から動作を付けます。
- 読み込み時は元の形状・骨格・ウェイト・材質を維持します。「原形を保って自動」「元の形を保持」「付属アニメーション」「既存の人型骨格」を選べます。骨格なしの立ち人型に限り、明示的に「簡易人型補完（試験的）」を試せます。「元の形に戻す」で、補完前のメッシュ・姿勢へ復元できます。
- 不明な関節名、非一様・反転scale、座り姿、独立した複数の骨格には人型補正を強制しません。付属アニメーションには足元IKを自動で重ねません。
- Draco・Meshopt・KTX2圧縮、外部ファイルを参照するモデルは対象外です。
- 写真・モデルは端末内で処理し、復元用にIndexedDBへ保存します。この処理からサーバーへアップロードしません。

## オブジェクトとの接触

建物・木の幹・街路家具・車・歩行者・室内設備・クラフト家具・所有物に、位置・回転・高さを持つ接触形状を登録します。キャラクターは横から当たると停止または壁に沿って移動し、低い物には段差として乗り上げます。頭上へのジャンプは物の下面で止まり、届いた物の上には着地できます。中庭の穴や高架下の空間は塞ぎません。家具を移動・回転・収納した際は、判定も更新します。

車と歩行者はプレイヤーの体に進入しないよう移動区間を確認します。形状判定はゲーム用のボックス・円柱・建物輪郭で行い、服のひだや葉の1枚ごとの柔らかい変形を物理計算するものではありません。

## MACHI REWARDS：原資と交換の動作確認

設定 →「交換の準備状況を開く」から「実際の報酬」と「動作確認」を切り替えます。**本番の暗号資産交換・送金は停止中で、実原資は0です。** 円やBitcoinを無限に生み出す処理はありません。ゲーム内所持金と初期所持金、セーブ内の金額は換金対象にしません。

動作確認では10,000検証MRを何度でも補充し、見積・申請・取消・検証上の完了まで操作できます。常に検証専用・換金不可と表示し、実台帳とは別のテーブルを使用します。1回の補充間隔は1.5秒、保有上限は1兆検証MRです。実ウォレットアドレスや秘密鍵は入力しません。

独自の初期運用案は、日本在住・18歳以上の確認済み受給者、1人1日100 MR、1 MR = 1 satoshi、最低10,000 MR・1回最大100,000 MRです。日付はJST、原資は運営が事前に用意した資金に限定します。**これは運用案で、現在BTCを受け取れるという約束ではありません。** 本番手数料は未確定です。

原資台帳は、サーバー側検証器が確認したBTC入金だけを記録する構造とし、報酬割当は記録済み原資以内に制限します。同一入金、同一受給者の同日受給、同じ申請の再送を重複記帳しません。入金検証器・実送金接続は未設定で、公開APIから実原資や実報酬を増やす入口はありません。

送金先は後から設定します。実運用には、資金と実接続、受給資格の確認、提供地域の運営条件、回復・照合処理を整える必要があります。詳細とAPIは `docs/EXCHANGE_READINESS.md` に記載しています。

## プロフィールと頭上の名前

表示名・ひとこと・自己紹介・称号・アイコン・アクセントカラーを編集できます。三人称視点では操作キャラクターの上に名前を表示し、プロフィールで表示を切り替えられます。一人称視点やメニューを開いている間は隠します。

ログインや会員登録は不要です。オンライン版では、このブラウザ用のプレイヤーを自動で用意し、プロフィールを保存します。表示名・紹介文・称号・アイコンは、ゲーム内のほかのプレイヤーが閲覧できます。チャットやフレンド一覧の名前からプロフィールを開けます。プロフィール設定はカード、肩書はバッジ、キャラクター設定は立体キューブのアイコンで表示します。

プレイヤーはブラウザの Cookie とサイトのドメインにひも付きます。サイトデータを消す、別のブラウザを使う、別のドメインへ移る場合は別のプレイヤーになります。以前の認証アカウントや別の保存先の内容を、新しいプレイヤーへ自動コピーしません。旧オンライン URL とカスタムドメインのデータも自動では引き継ぎません。

## 現実の時計と音楽

ゲームの時計と日付は、端末の現実のローカル時刻に同期します。メニュー表示中や一時停止中も時計は進み、別のタブから戻ると現在時刻に合わせます。食事・仕事・休息の操作で表示時刻を飛ばすことはありません。

| 端末の時間帯 | 指定音源 | 配置ファイル |
|---|---|---|
| 朝 05:00〜10:59 | 00001 | `dist/audio/morning-00001.mp3` |
| 昼 11:00〜17:59 | 00002 | `dist/audio/day-00002.mp3` |
| 夜 18:00〜04:59 | 00003 | `dist/audio/night-00003.mp3` |

街に入る操作をきっかけに、その時間帯の曲をループ再生します。時間帯が変わると曲を切り替えます。「音楽・環境音」ではBGMのオン・オフ、音量、再生を操作でき、環境音はBGMと別に切り替え、音量も個別に調整できます。ブラウザが再生を制限した場合は「再生する」を押してください。別のタブやアプリへ移動している間はBGMを休止します。

## 物の位置から聞こえる環境音

車・歩行者・木々・水辺・建物・冷蔵庫・換気設備などに音源を設定し、キャラクターからの距離と視点の向きを反映します。車と人の音源は移動に追従し、壁を挟むと音量と高音を抑えます。ドア・家具・持ち物は、開く・使う・動かす・手入れする操作が成功した場所で音を鳴らします。足音は足元の地面・草・木床に合わせます。

環境音はゲーム内で合成する効果音で、現地の録音やライブ配信ではありません。全オブジェクトの音源情報を保持し、聞こえる範囲の近い音から同時再生します。常時音を出さない家具は操作音を持ちます。描画品質に応じて常時音源は6〜26、操作音は最大8、フェードアウト中の音は最大4に制限し、不要になった音源を停止します。街区や室内の切替、タブの非表示でも後の音を残しません。

初回は環境音が有効です。以前にオフで保存した設定は保持します。「メニュー → 音楽・環境音」でオンにし、「環境音を確認」から再生を試せます。

## 景観と街の動き

道路を曲がり角・交差点でつなぎ、重なる路面を取り除きます。歩道と縁石には実際の段差を作り、地形に沿った緑地と建物の基礎を生成します。建物の輪郭を保ちながら、外壁の窓開口・奥まったガラス・入口を加えます。OSMに記録されたベンチ・街灯・ごみ箱・水飲み場も表示します。

建物や室内には実寸の模様、表面の凹凸・粗さを持つPBR素材を使用します。アスファルト・コンクリート・煉瓦・タイルを描き分け、枝と葉に隙間のある樹木、連続した空の色、時刻に応じた影と反射光を組み合わせます。描画品質に応じて負荷を調整します。空と太陽は端末時刻に合わせたゲーム表現で、場所ごとの正確な天文・実際の天候を計測しているものではありません。導入画面のCGイラストにはコンセプトビジュアルと表示しており、実際のゲーム画面や現地の写真ではありません。

街の歩行者・車は道路の経路と時刻に応じたシミュレーションです。現実の人や車の位置をリアルタイムで観測・配信するデータは接続していません。画面にもシミュレーションである旨を表示します。

## 自宅とセーブ

自宅の家具を間取り図で配置・移動・回転し、壁・床・家具の色を変更できます。配置は3D室内に反映します。家具の重なりや玄関の通り道には制限があります。

オンライン版の部屋は、ブラウザにひも付いたプレイヤーの保存先へ同期します。暮らし・設定はブラウザに保存します。セーブJSONの書き出し・読み込みに対応しますが、写真や3DモデルはJSONに含まれません。別の端末やURLへ移す場合は元のファイルを再度読み込んでください。

## 所有物と生活感

街のゲーム内フリーマーケットでは、植物・チェア・照明・テーブル・本棚を購入して、自分の所有物にできます。名前・色の変更、修理、手入れ、収納に対応します。所有物メニューから、自分の部屋へ家具を移せます。実在する物の所有権を扱う機能ではなく、プレイヤー別のゲーム用の物品です。

自宅では照明の切り替え、掃除、植物の水やりができます。オンライン版の所有物は、このブラウザのプレイヤーにひも付けて保存します。通信に失敗した場合は画面に表示し、再同期できます。

## オンライン版とGitHub Pages版

公開ゲームの入口はオンライン版です。GitHub Pagesのゲーム入口を開いた場合も、最初からオンライン版へ自動移動します。チャット・フレンド・組織・音声通話・プロフィール・自宅・所有物は、ログイン操作なしで利用できます。サイトを開くとブラウザ用の接続を自動で準備し、オンラインAPIはSites Workerで処理します。ChatGPTアカウントは必要ありません。

GitHub Pages自体には静的ファイルだけを配信します。リポジトリのルート入口はオンライン版へ移動します。ゲーム本体の`dist/`はローカル開発で自動移動しません。カスタムドメインがSites Workerにつながると、そのドメイン内で地図・プロフィール・チャットなどのAPIを利用します。

ブラウザを識別する Cookie は JavaScript から読めない設定で発行し、サーバーはその値のハッシュだけを保存します。保存や送信時にはプレイヤーIDも照合し、別タブなどで接続先のプレイヤーが変わった場合に、ほかのプレイヤーとして処理を続けないようにしています。

音声通話は明示的な参加操作後にマイクを要求し、WebRTCを利用します。ネットワーク条件やTURN中継の設定によって接続できない場合があります。TURNなどの認証情報を静的ファイルやリポジトリへ書き込まないでください。

## ローカルで実行

`dist/`内の静的版はビルド不要です。Three.jsと必要なローダーは`dist/vendor/`に同梱しています。main/root公開用のルートHTMLとSEOアセットは、変更後に`node scripts/build.mjs`で同期してください。

```bash
python3 -m http.server 8000 --directory dist
```

ブラウザで `http://localhost:8000/` を開きます。ファイルを直接ダブルクリックする`file://`実行は、ES Modulesやブラウザのセキュリティ制限により対象外です。公開時はHTTPSを使用してください。JavaScriptとWebGL 2、対応するGPUが必要です。

構文確認と回帰テスト:

```bash
node scripts/check.mjs
node --test tests/*.test.mjs
```

プロフィールAPIのテストはPython 3標準のSQLiteを使います。テストは地図中継・取得経路、ブラウザの接続・保存先の分離・競合、モデルのモーション、歩行面・段差・坂、GPS座標変換、現実時刻、時間帯BGMの切り替えを対象にしています。外部データの実際の到達性やGPU描画は別途実環境で確認してください。

確認する主な操作は、初回起動、現在地取得の許可・拒否、住所検索・座標入力、失敗後の同地点再試行、街の移動、入退室、生活行動、家具編集、プロフィール、写真・モデルの復元、タッチ操作、ゲームパッドです。オンラインの自動接続・保存・通話はオンライン版で確認します。

## mainから自動公開

既存の「Deploy from a branch → main / (root)」と「GitHub Actions」の両方に対応しています。`node scripts/build.mjs` は、`dist/`のゲームからルートの`index.html`・`about.html`・SEOアセットを同期します。どちらのPages配信方式でも、ゲーム入口はネイティブのオンラインURLへ自動移動します。`_config.yml`はREADMEによるトップページ化を防ぎ、Worker・開発スクリプト・依存関係・設定ファイルをJekyll配信から除外します。

main更新のワークフローは、GitHub Pages APIを読み取って現在の`build_type`を確認します。`legacy`（main/root配信）の場合は検証だけで終了し、GitHub標準のブランチ公開に任せます。`workflow`の場合だけ静的アーティファクトを配置します。Pages設定を変更するAPIは呼びません。この分岐で二つの配信による上書き競合を避けます。

ワークフローは`contents: read`、`pages: write`、`id-token: write`だけを要求します。ビルド時のnpmインストールは不要です。canonical・サイトマップ・OGPのURLは `https://www.omoji-z.com/` を使用します。`CNAME`もこのドメインを保持します。ゲームのオンライン接続先は`dist/site-config.js`でまとめ、カスタムドメインと既存オンラインURLでは、それぞれ開いているサイト内のAPIを使用します。

オンライン版は `node scripts/build.mjs` で同じ静的ファイルを含むWorkerを生成し、Sitesの公開処理でD1マイグレーションとともに配置します。Pagesのワークフローはオンライン版のサーバーをデプロイしません。サーバー変更時はオンライン版も更新してください。Node.js 24以降の開発プレビューは `npm run dev`。ローカルSQLiteを使用します。

### カスタムドメインの接続

`www.omoji-z.com` はゲームのWorkerにも登録します。GitHub PagesのCNAME設定だけでは、チャットや保存のAPIは配信できません。DNS管理画面で、Sitesから指定されたCNAMEと所有確認用TXTレコードを設定し、ドメイン・SSLの状態が有効になっていることを確認してください。DNS反映中も既存のオンラインURLは利用できます。

MP3はWorkerのJavaScriptへ埋め込まず、`/audio/`からリポジトリの`main/dist/audio/`にある音源をストリーミングします。音源を新規追加・変更するときは、先にGitHubのmainへ反映してからオンライン版を公開してください。ローカルの静的プレビューでは`dist/audio/`を直接使用します。

## 外部データと制限

- 住所検索: [Photon](https://github.com/komoot/photon)の公開API。検索ボタンで送信した住所・地名から候補を取得します。入力のたびに自動送信する検索ではありません。検索語は検索提供元へ送信されます。
- 地図: © OpenStreetMap contributors / [ODbL](https://www.openstreetmap.org/copyright)。オンライン版の`/api/world`を通じて[公開Overpass API](https://wiki.openstreetmap.org/wiki/Overpass_API)を利用します。日本周辺ではDresel Asiaを先に試し、一時的な接続・配信障害の場合はPrivate.coffeeを試します。それ以外の地域はPrivate.coffeeを使用します。429・406など利用制限の応答は、自動の配信元変更で回避しません。
- 地図クライアントは中継に最大45秒、その接続経路が利用できない場合だけ直接取得に最大10秒を割り当て、全体で最大55秒に制限します。ブラウザの地図キャッシュは最大4件・24時間、中継のキャッシュは15分です。公共APIの混雑や障害時の成功は保証しません。
- 地形: [Mapzen Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)のTerrarium形式を`/api/terrain/`経由で取得します。地域ごとの元データは[帰属情報](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)を参照してください。DEMは近似標高です。
- 地図の取得先へは緯度経度、標高配信元へは周辺タイル番号が送られます。現在地を他プレイヤーへ自動共有しません。住所検索も地図読み込みも、地図の検索・表示のための通信です。
- 位置情報や地図データが利用できない地域、未記録の建物、古いデータがあります。未取得の地域全体を事前収録しているわけではありません。
- 大きなモデル、高解像度、端末の発熱・メモリー不足は描画速度に影響します。品質設定を調整してください。
- ブラウザのサイトデータ削除、保存容量不足、プライベートモードでは端末内データが残らない場合があります。
- アプリマニフェストとホーム画面アイコンを提供しています。全世界の地図をオフラインで利用する機能はありません。
