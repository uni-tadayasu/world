# 要望と実装・検証の対応

最終監査日: 2026-11-25

この文書は、実装された処理と、外部データや実機確認が必要な範囲を区別するための開発記録です。「実装済み」はコードと利用導線が存在することを示し、すべての端末・場所・モデルでの動作保証ではありません。公開の完了は、GitHub の main とオンライン版の公開結果で別途確認します。

## モデル・景観・環境音の再改修

- 修正前の人型モデルでは、読み込み直後だけで最大約0.827mの頂点移動を再現した。番号骨格と非一様scaleでも約0.821m／0.650mの破綻を確認。既定の骨格推定と腕の約90度の姿勢変更を除去した。
- 修正後は素のGLTFLoaderとすべての頂点を比較し、衣服・髪・morph・特殊なrest軸・補正inversebind・複数skinを含め原形を維持する回帰を追加。近似生成から元形へ2往復しても元のMesh／Geometry／Materialと姿勢を復元する。
- 実ワールド生成コードのメッシュへRaycasterを当て、交差点が一重の面になること、歩道の高さ、窓開口と奥まったガラス、斜面の基礎、地形に沿う緑地を照合する。地図にない樹木を緑地へ無作為に追加しない。
- 景観改修時に計測した大規模fixture（道路1,000線分・建物324件）のCPU初期生成は同環境で約2.36秒から約2.83秒。歩行面10,000回の照会は約15ms。これはGPU描画性能や実端末FPSの計測ではない。
- 地図キャッシュはv2に更新し、旧キャッシュに含まれない街灯の取得を妨げない。既存の55秒以内の取得上限や失敗時の導線は維持する。
- 屋根・幹・柱への落下と建物の下面にも接触判定を追加した。屋根は建物の最大高さを用いる保守的な支持面で、斜屋根に沿う精密な歩行ではない。
- 音源はオブジェクトの現在座標を使用する。移動・収納・室内切替・停止時に不要な音を解放し、音響処理に失敗しても家具の保存・購入等の結果を変えない。

## 検証の範囲

- 今回のリリース準備で `node scripts/check.mjs` と `node --test tests/*.test.mjs` を実行し、263件合格・失敗0件を確認した。モデル保持・道路形状・PBR材質・空間音響・物体接触・暗号資産交換の準備台帳に加え、実資産と分離した交換サンドボックス、検証済み原資の台帳、スポンサー支払通知・掲載審査・画面操作を含む。
- スポンサーの支払テストは合成した署名付きイベントとローカル SQLite を使う。本番のStripe商品・Payment Link・Webhookは未登録で、実際の購入・入金・返金、実Stripe環境での一連の購入操作は未検証。公開画面は購入受付を無効にする。
- `node scripts/check.mjs` は構文と入口のアセットを確認する。
- `node --test tests/*.test.mjs` は地図の取得経路、ブラウザの接続とプロフィール、部屋／所有物の所有者確認、時計、BGM、コントローラー、チャット画面の取り違えを含む回帰テストを実行する。歩行制御・歩行面・モデルモーション・GPS 座標変換・main 統合も専用テストで検証する。リリース時はテスト全体の実行結果を確認する。
- API テストはローカルの SQLite と合成ユーザーを使用する。実在の相手へチャットやフレンド申請を送信して検証してはいない。
- 地図・住所検索・音源の公開サービス到達性は、自動テストのモック応答とは別に確認する必要がある。前回公開版では東京駅周辺の地図、東京駅の住所候補、ゲストプロフィール保存、昼の指定 BGM を確認済み。これは現在地や全地域での成功を意味しない。
- 実ワールド生成コードから書き出した同じメッシュ・RGBA素材をBlenderで描画し、窓の奥行き・壁の向き・素材の縮尺・斜面の基礎を確認した。検証用街区と別レンダラーを使用した内部QAで、実際のGPS地点やWebGLゲーム画面の確認ではない。
- 今回利用している確認用ブラウザは WebGL が無効になっている。CPU 上のモデル・座標・モーション計算の検証と、実機での GPU 描画・見た目の確認を区別する。
- 実物のすべてのゲームパッド、スマホ／タブレットの全機種、任意のユーザーモデル、実マイクを使う複数端末通話は未網羅。特に独自骨格・圧縮されたモデル、GPU／メモリ制限、通信環境による挙動は実機で確認する。

## 外部サービス・データが必要な未完了範囲

現実世界そのものと同一の街並み・内装、現実の全通行人・車のライブ位置、任意の写真から精密な立体形状・リグ・Motion を復元する処理は、現在の公開 OSM／DEM とブラウザ内の簡易生成では得られない。実測 3D データ、利用可能な観測配信、写真から 3D を生成する処理と実行環境などが必要になる。未接続の外部データを「再現済み」「リアルタイム同期済み」と表示しない。
