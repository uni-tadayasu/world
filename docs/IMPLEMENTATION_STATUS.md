# 要望と実装・検証の対応

最終監査日: 2026-11-25

この文書は、実装された処理と、外部データや実機確認が必要な範囲を区別するための開発記録です。「実装済み」はコードと利用導線が存在することを示し、すべての端末・場所・モデルでの動作保証ではありません。公開の完了は、GitHub の main とオンライン版の公開結果で別途確認します。

## 今回の監査で見つけた追加不具合

| 不具合 | 修正・確認 |
|---|---|
| スティックのないパッドが移動できない、不要な軸を無効化できない | 十字キー移動、方向ボタンの再割り当て、軸 `-1`、対角入力の速度正規化。`tests/gamepad.test.mjs` で検証。 |
| パッドでメニューを閉じた同じフレームに、一時停止が再表示／ジャンプ入力が漏れる | `main.js` でメニュー入力をそのフレーム内で消費し、ゲーム中の入力と分離。`tests/main-integration.test.mjs` で START 再表示と決定入力の漏れを検証。 |
| DM 相手をブロックすると旧 DM が全体チャットの見出し・送信先の下に残る | 通信を待つ前に private 履歴と cursor を消し、全体チャットを先頭から取得。状態取得が失敗しても private 履歴を残さない。`tests/social-client.test.mjs` で正常・遅延／失敗を検証。 |
| オンラインでも持ち物の初回同期が呼ばれない | 実在の街を最初に読み込んだ際に `possessions.sync()` を実行。ブラウザの接続取得／同期をクライアント・API テストで検証。 |
| 保存・再取得中の接続変更で、部屋／所有物を別プレイヤーへ書き込み・キャッシュできる | 保存する側が `expectedUserId` を送り、サーバー側で現在のプレイヤーと照合。不一致は 409。取得結果の `userId` もキャッシュ前に確認。別の保存先の未同期データは元のキャッシュに保持。`tests/possessions-client.test.mjs` と実 SQLite の `tests/profile-api.test.mjs` で検証。 |
| 初回に複数画面・タブを開くとブラウザの接続作成が競合する | 画面間で初回リクエストを共有し、対応ブラウザでは Web Locks でタブ間も直列化。チャット等の変更 API にも `expectedUserId` の確認を設け、接続が変わった状態で別のプレイヤーとして送信しない。 |

## 検証の範囲

- 今回のリリース準備では `node scripts/check.mjs` と `node --test tests/*.test.mjs` を実行し、Node テスト集計で 80 件合格・失敗 0 件を確認した。
- `node scripts/check.mjs` は構文と入口のアセットを確認する。
- `node --test tests/*.test.mjs` は地図の取得経路、ブラウザの接続とプロフィール、部屋／所有物の所有者確認、時計、BGM、コントローラー、チャット画面の取り違えを含む回帰テストを実行する。歩行制御・歩行面・モデルモーション・GPS 座標変換・main 統合も専用テストで検証する。リリース時はテスト全体の実行結果を確認する。
- API テストはローカルの SQLite と合成ユーザーを使用する。実在の相手へチャットやフレンド申請を送信して検証してはいない。
- 地図・住所検索・音源の公開サービス到達性は、自動テストのモック応答とは別に確認する必要がある。前回公開版では東京駅周辺の地図、東京駅の住所候補、ゲストプロフィール保存、昼の指定 BGM を確認済み。これは現在地や全地域での成功を意味しない。
- 今回利用している確認用ブラウザは WebGL が無効になっている。CPU 上のモデル・座標・モーション計算の検証と、実機での GPU 描画・見た目の確認を区別する。
- 実物のすべてのゲームパッド、スマホ／タブレットの全機種、任意のユーザーモデル、実マイクを使う複数端末通話は未網羅。特に独自骨格・圧縮されたモデル、GPU／メモリ制限、通信環境による挙動は実機で確認する。

## 外部サービス・データが必要な未完了範囲

現実世界そのものと同一の街並み・内装、現実の全通行人・車のライブ位置、任意の写真から精密な立体形状・リグ・Motion を復元する処理は、現在の公開 OSM／DEM とブラウザ内の簡易生成では得られない。実測 3D データ、利用可能な観測配信、写真から 3D を生成する処理と実行環境などが必要になる。未接続の外部データを「再現済み」「リアルタイム同期済み」と表示しない。
